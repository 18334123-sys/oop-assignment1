# MiniMart Inventory System

## Project Description
A simple inventory system using Python OOP.

## Files
- product.py: Manages product information.
- inventory.py: Manages store inventory.
- main.py: Runs the program.

## How to Run
1. Open the project in PyCharm.
2. Open main.py.
3. Click Run.

## Design Decisions
The program uses classes, properties,
validation, class methods and static methods
to manage products and inventory.
